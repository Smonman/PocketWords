# PocketWords

Reads in an eBook file, and extracts all words from it.
Currently, only `.epub` files are supported.

## Synopsis

```bash
java PocketWords-1.0.0-SNAPSHOT.jar [-h] -i <arg> [-o <arg>] [-v]
```

Options:

| Option                      | Description             |
|-----------------------------|-------------------------|
| `-h`, `--help`              | Print help message      |
| `-i`, `--input-file <arg>`  | Path to the eBook file  |
| `-o`, `--output-file <arg>` | Path to the output file |
| `-v`, `--version`           | Prints version          |
